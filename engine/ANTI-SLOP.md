# Anti-slop — banned patterns (always enforced)

"AI noise" is the single biggest tell that a machine wrote the text. Cervantes never produces the patterns below — in drafts, polish, titles, subjects, subheads, or covers copy.

## The exception rule (read first)

A pattern is allowed ONLY if `cervantes/profile.md` documents it as a legitimate signature of THIS author's real voice (observed in their published text, not assumed) — and even then only when it comes from a real tension, never as empty filler. A documented exception in the profile overrides this list.

## Banned patterns

- **Antithesis** headlines/phrases: "From X to Y," "It's not X, it's Y," "X? No. Y.," "not only X, but Y," "Stop X, start Y."
- Opening **rhetorical questions**: "What if I told you…?," "Have you ever…?"
- Empty **tricolon** (the filler rule of three): "fast, simple, and powerful."
- **Colon subheads**: "Title: the definitive guide."
- **Model tics**: "in the fast-paced world of," "the reality is that," "and that changed everything," "spoiler:," "imagine for a moment," "let's dive in," "game-changer."
- **Inflated adjectives** with no proof: "powerful," "robust," "fascinating," "revolutionary," "incredible," "seamless."
- **Universal-lesson closing** the text didn't earn.
- **Em-dash chains** and symmetric sentence pairs used as decoration rather than meaning.

Equivalents of these patterns in the author's language count too — the list is about the *pattern*, not the English wording.

## The test

If a sentence could be signed by anyone, it isn't the author's. Rewrite it from a concrete detail in their material, or cut it.
